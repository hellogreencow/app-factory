# App Category Templates

Templates define patterns per app type so agents have clear scaffolding.

## Planned Templates

- **crypto**: Portfolio, prices, add/remove assets, charts
- **sci-fi**: Story reader, chapters, bookmarks, themes
- **utility**: Generic CRUD, settings, list/detail

## Template Format

Each template includes:
- `features.json`: List of features to implement
- `prompts/`: Agent prompts tailored to the category
- `flows/`: Example Maestro flows (optional)
